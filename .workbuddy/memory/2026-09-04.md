- 【已实施·指纹拆分】openclaw-preflight.mjs：
  - check lane 新指纹 checkLaneFingerprint = sha256(git diff --binary base...head 全文) + 根目录 config blobs（tsconfig/lint 配置，git ls-tree HEAD 过滤 blob）+ 工具链/env。跨 rebase/squash 内容不变即命中。diff 读取失败时指纹为空，lane 不缓存不复用（fail-safe）。
  - focused tests 指纹 headSha → HEAD^{tree}（schemaVersion 2）：tree 是测试真实输入的内容身份。squash/amend/内容保持型 rebase 命中；rebase 到新 main 时 tree 变化正确 miss。
  - 整组 heavyFingerprint（headSha 键）保留作保守快路径。写缓存/读缓存调用点同步更新（validationChecksByFingerprint 改用 checkLaneFingerprint）。
  - HEAD^{tree} 并入开头批量 rev-parse，零额外进程。git ls-tree + git diff --binary 共 +2 个 gitMs 进程。
- 【已实施·squash 脚本】scripts/openclaw-squash-pr-commits.mjs（新）：
  - 前置校验：workflow.branch 匹配、worktree 干净、base 是 HEAD 祖先；base..HEAD 所有提交 author+committer email 必须等于所选账号（resolveAccount），否则拒绝（绝不重写他人提交）。
  - workflow.pr 存在时经 gh 核对远程 PR 提交作者 login（硬校验，gh 失败降级 warning）。
  - squash 实现：git reset --soft base + git commit -C <oldest>（保留最早提交的消息/作者/作者日期，committer 用 worktree 配置=账号身份），结构上保 tree；失败时 reset --soft 回滚到原 head。支持 --dry-run。输出 JSON（squashed/commitsBefore/treeUnchanged/...）。
  - 单测 tests/squash-pr-commits.test.mjs 5 个：多提交 squash 保 tree、外部 author 拒绝、committer 不同拒绝、单提交 no-op、dry-run 不改历史。
